# Elevate Lab Internship — Task 4: Dashboard Design 📊

## 📌 Objective
To design an interactive, executive-level dashboard that empowers business stakeholders to make data-driven decisions based on financial trends and geographic performance.

## 🛠️ Tools & Technologies
* **Business Intelligence:** Power BI
* **Presentation/Reporting:** PowerPoint
* **Dataset:** Adidas US Sales Dataset (Kaggle)

## ⚙️ Key Features & Technical Highlights
This project was designed as a multi-page data application to provide both high-level insights and granular data exploration:

1. **Executive KPIs & Time-Series (Overview):** Implemented high-level summary cards tracking Total Sales ($1.00B) and Operating Profit ($341.31M). Designed a continuous line chart to visualize monthly sales momentum and seasonal peaks across 2020 and 2021.
2. **Multi-Page Navigation:** Built a custom Page Navigator allowing users to seamlessly toggle between the high-level "Overview" page and the granular "Data Details" page.
3. **Advanced Filtering (Sync Slicers):** Configured synced slicers across multiple pages, ensuring that adjusting the geographical region or date on one page instantly updates the metrics across the entire application.
4. **Hierarchical Data Matrices:** Designed a detailed matrix visual allowing stakeholders to drill down from high-level Retailer performance directly into specific Product sales categories.
5. **Professional UI/UX:** Applied a cohesive, high-contrast theme to ensure readability and a premium application feel.
