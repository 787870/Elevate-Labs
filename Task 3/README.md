# Elevate Lab Internship — Task 3: SQL for Data Analysis

## 📌 Objective
To extract, manipulate, and analyze structured data using SQL. This task demonstrates proficiency in writing complex queries to derive actionable business insights from a relational e-commerce database.

## 🛠️ Tools & Technologies
* **Database Management System:** MySQL / MySQL Workbench
* **Language:** SQL

## ⚙️ Key Skills Demonstrated
1. **Data Retrieval & Filtering:** Used `SELECT`, `WHERE`, and `ORDER BY` to isolate specific order dates and sort by transaction volume.
2. **Data Aggregation & Joins:** Utilized `JOIN` statements to combine `Customers`, `Orders`, and `Products` tables. Applied `GROUP BY` alongside the `SUM()` aggregate function to calculate total revenue generated per customer.
3. **Subqueries:** Implemented nested queries to identify specific customer purchasing behaviors based on product IDs.
4. **Database Views:** Created a reusable virtual table (`VIEW`) named `DailySales` to streamline the tracking of daily item sales metrics.
