# Elevate-Labs

Data Cleaning and Preprocessing internship project repository containing Python notebooks, preprocessing techniques, and data handling workflows using Pandas, NumPy, and Google Colab.

## 📌 Project Overview
This repository includes internship tasks focused on:
- Data Cleaning
- Data Preprocessing
- Handling Missing Values
- Removing Duplicates
- Feature Engineering
- Data Transformation
- Exploratory Data Analysis (EDA)

## 🛠 Technologies Used
- Python
- Pandas
- NumPy
- Google Colab
- Jupyter Notebook
